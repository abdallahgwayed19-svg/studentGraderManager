# Student Grade Manager (C++)

A beginner-friendly console application for managing student names and grades.

## Features
- Add a student and a grade between 0 and 100
- Reject invalid grade input
- Prevent duplicate student names
- Display all students and grades
- Calculate the class average
- Find the highest grade
- Search for a student by exact name
- Handle invalid menu input

## Requirements
A C++ compiler that supports C++11 or later.

## How to run
1. Open `main.cpp` in a C++ IDE or online compiler such as Programiz.
2. Compile and run the program.
3. Choose a menu option by entering its number.

## Notes and current limitations
- Data is stored in arrays while the program is running.
- Data is not saved after the program exits.
- Student names are currently entered as one word.
- The program supports up to 100 students.

## Concepts practiced
C++ functions, arrays, loops, conditionals, input validation, and basic searching.

## Future improvements
- Support full names with spaces
- Save and load student data from a file
